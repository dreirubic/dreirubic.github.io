Automation Case Study

From random prompts to one reusable master prompt

How I replaced one-off AI prompting with a systematic prompt that produces consistent, standalone interactive reviewers, lessons, and mock exams for my students.

  • Prompt design
  • Instructional design
  • Process documentation
  • AI-assisted workflows

Before and after

Before

Random prompting

  • I typed a fresh, loosely worded prompt for every reviewer I made for my students.
  • Results were hit-or-miss, and topic coverage was uneven from one reviewer to the next.
  • No fixed structure, so every new material meant starting over.
After

Systematic prompting

  • One master prompt with the same teaching rules, structure, and design every time.
  • More reliable reviewers with better coverage of each topic.
  • Consistent look and behavior across every lesson I generate.

How the system works

1

Core prompt

Fixed rules that never change: the learner-first teaching approach, a required seven-step learning flow, and the technical and design standards.

  • Bloom's Taxonomy progression
  • Chunking
  • Scaffolding
  • Retrieval practice
  • Misconception correction
+
2

Modifier blocks

Swappable add-ons that tune the result, so I change a block instead of rewriting the prompt.

  • Output type: reviewer, lesson, mock exam, flashcards, activities
  • Grade profile
  • Subject profile
+
3

Input block

A short fill-in template that carries the details of each new material.

  • Topic
  • Grade level
  • Difficulty
  • Learning objectives
  • Output type
  • Study time
  • Special instructions
Result: one standalone, interactive HTML file that teaches without a tutor

What I fill in each time

Topic: Pure substances and mixtures
Grade Level: Grade 7
Difficulty: Moderate
Learning Objectives: Classify matter; explain solutions
Output Type: Reviewer
Estimated Study Time: 20 minutes
Special Instructions: End with a short mini-test

Illustrative example of the input block. The core prompt and modifier blocks stay the same.

Results

  • More reliable output: the same standards apply to every generation, so I spend less time fixing weak results.
  • Better topic coverage: learning objectives and a fixed learning flow keep each material complete.
  • Consistent quality: every file shares the same look, feedback style, and structure, whatever the subject or grade level.
  • Easy to share: each result is a single HTML file students can open on any device, with no tutor needed.
  • Easy to adapt: a new grade, subject, or material type means swapping a block, not starting over.

I use this method for every interactive HTML material I generate.

Why it matters for client work

The same idea works for recurring VA tasks such as weekly reports, listing write-ups, follow-up emails, and trackers: one reusable prompt plus a short input form, so the work comes out consistent every time and is easy to hand off.
